# Tic Toc cinematic proof build

This flagship proof applies the six production experience modes to one luxury watch narrative:

- Scroll storytelling through the hero, calibre, materials, wrist, and acquisition chapters
- Floating navigation and persistent scene progress
- Interactive material and configuration cards
- Big hero typography built around the product silhouette
- Product-focused motion and scroll-linked winding cues
- A four-stage immersive private checkout with configuration persistence

## Live experience

[Open the private Tic Toc build](https://tic-toc-obsidian.hotheelz.chatgpt.site)

## Product

No. 01 Obsidian Tourbillon, a fictional 88-piece launch edition priced at $18,800 USD. The checkout is a functional concept flow and does not process payment.

## Run locally

Serve this directory with any static file server, or open `index.html` directly.

See `BRAND_DIRECTION.md` for the visual, verbal, and product system.
