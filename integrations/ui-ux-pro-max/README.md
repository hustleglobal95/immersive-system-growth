# UI/UX Pro Max Integration

Use UI/UX Pro Max as a design review and interface reasoning layer, not as the 3D renderer.

Recommended flow:

1. Establish the spatial scene plan in Forge.
2. Use UI/UX Pro Max to review hierarchy, typography, controls, responsive behavior and interaction clarity.
3. Keep WebGL content subordinate to the visitor's task and conversion goal.
4. Re-run the cinematic audit after applying UI changes so layout edits do not break spatial timing.
