# Third-Party Components

Forge source code in this repository is provided under the MIT license. Runtime behavior depends on third-party npm packages that retain their own licenses and terms.

Core packages include Next.js, React, Three.js, React Three Fiber, Drei, Lenis and Zustand, which publish permissive open-source licenses in their current packages. Postprocessing and React Three Postprocessing retain their own published licenses.

GSAP is distributed under GreenSock's current standard no-charge license rather than the Forge MIT license. Review its license for your intended distribution model.

Optional integrations documented but not vendored include r3f-scroll-rig, UI/UX Pro Max and Theatre.js.

Before commercial redistribution, review the exact licenses and versions resolved by your package manager. This repository intentionally does not copy source code from those optional projects.
