# Broader Immersive Web Construction Corpus

Reviewed: **2026-09-18**

This corpus expands Forge beyond GetLayers so Director does not overfit to one marketplace, one studio, one visual trend or one implementation style.

It contains **84 public studio case studies, technical breakdowns and source studies** from Dogstudio, Lusion, makemepulse, Bonhomme, 14islands and Codrops.

Combined with the 49-template GetLayers corpus, Forge now has **133 immersive references** and **78 executable construction patterns**.

## What this corpus is for

The goal is to learn recurring construction logic:

- how studios stage one dominant subject;
- how they split semantic DOM and spatial rendering;
- how they keep long experiences continuous;
- how they author camera paths;
- how they connect interaction to a brand or story idea;
- how they reduce expensive rendering without reducing the concept;
- how they make transitions serve both narrative and resource scheduling;
- how they preserve the same experience on mobile through fidelity changes or medium substitution.

The goal is **not** to copy a studio's exact visual identity, proprietary engine or source code.

## Important cross-studio lessons

### 1. Interaction is strongest when it has semantic consequence

Black Messiah, Dash and ZERO all reinforce the same rule from different directions:

- the interaction changes meaning;
- the interaction behaves like the brand idea;
- or the interaction is itself the narrative threshold.

Forge should ask **what the visitor causes**, not merely what moves under the pointer.

### 2. High fidelity often comes from substitution, not brute force

Virgin Galactic, Max Mara and Turn of the Screw all show versions of the same production idea:

- use precomputed environment maps instead of costly realtime reflection;
- bake or precompute lighting when the user does not benefit from solving it live;
- cull geometry against the actual camera corridor.

Forge should optimize perceived result, not defend expensive implementation for its own sake.

### 3. The camera is a design constraint

Turn of the Screw and Carrera demonstrate that a camera path can be the page structure itself.

Once the allowed camera corridor is known, Forge can:

- art-direct every reachable frame;
- remove geometry the camera can never see;
- choose focal/lens behavior intentionally;
- adapt a separate portrait corridor for mobile.

### 4. Mobile can keep the concept while changing the medium

Stefan Vitasović swaps desktop WebGL for HTML5 video on mobile while preserving interaction/motion language. Weleda uses enhanced 360 environments for a mobile-first spatial experience.

Forge should not interpret "preserve the concept" as "run identical code everywhere."

### 5. A transition is also resource choreography

Virgin Galactic's subscenes and Weleda's linked 360 environments reinforce that the scene boundary is where:

- next assets must already be ready;
- previous assets can be released;
- visual overlap hides the swap;
- the carried anchor tells the visitor that continuity remains intact.

### 6. Authoring formats should not dictate runtime formats

Of The Oak and Worldcoin Globe both replace obvious object-by-object delivery with runtime-specific data representations.

Forge should be willing to:

- flatten;
- quantize;
- instance;
- texture-encode;
- bake;
- or otherwise reconstruct authoring data for the GPU.

### 7. Immersive worlds need content architecture

Virgin Galactic, DEPT Pioneer and A World With No Heroes all use spatial experiences without trapping information inside the scene.

Worlds get:

- hotspots;
- direct routes;
- media cards;
- event systems;
- structured content paths.

This is what keeps a spatial website usable rather than turning it into a demo.

### 8. Story structure comes before technology

The Spark, Podium, Audemars Piguet and La Prairie all organize the experience around narrative stages before deciding where 3D belongs.

Forge should be able to build:

- a full persistent 3D world;
- a selective WebGL/DOM hybrid;
- an enhanced 360 journey;
- or an almost entirely editorial experience

from the same Director process.

### 9. Source study adds implementation-order knowledge

The official Basement Grotesque and Bruno Simon repositories add a deeper layer than visual/case-study analysis:

- responsive art direction may require separate authored coordinate systems, not only CSS scaling;
- motion coherence comes from shared timing/easing primitives before individual section choreography;
- frame execution order should be explicit in large interactive worlds;
- startup should be staged around the first meaningful experience instead of every asset;
- authored scene metadata can drive activation/culling at runtime;
- input devices should map to semantic actions;
- pre-rendering representative scene states can move compilation/upload cost before interaction.

This is exactly the level Forge should keep accumulating: not another dependency list, but proven ways to structure immersive production.

## Retrieval policy

Director now retrieves from the combined **133-reference corpus**, not the GetLayers set alone.

Retrieval deliberately limits source monoculture: when enough candidates exist, no single source host can dominate the selected precedent set. The Director can therefore combine, for example:

- a GetLayers visual composition;
- a Dogstudio scene-transition lesson;
- a Lusion asset-pipeline lesson;
- a Codrops technical motion pattern;
- a Bonhomme interaction principle.

The result should be a new client-specific experience, not a collage of copied executions.
