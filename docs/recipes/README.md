# Experience Recipes

JSON recipes in `/recipes` are working experience configurations. Apply one with:

```bash
npm run recipe:list
npm run recipe:apply -- real-estate
```

Current recipes: burger showcase, real estate, restaurant, product, SaaS and automotive.

The burger showcase is the advanced reference for named-node product choreography and semantic commerce modules.

Recipes are starting choreography, not final art direction. Replace camera coordinates and object transforms after importing your actual assets.
