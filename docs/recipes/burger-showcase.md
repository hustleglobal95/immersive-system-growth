# Burger showcase

Apply with:

    npm run recipe:apply -- burger-showcase

This is the full product-choreography reference. It uses an original named-node burger GLB, global ingredient tracks, six continuous camera scenes, semantic statement modules, a brand band, a responsive menu grid and an order card.

Replace the procedural fixture with an art-directed product model before client delivery. Preserve the required node names or update the rig configuration and run the rig audit.
