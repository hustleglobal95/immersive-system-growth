## Automated evidence

Local clean installation, `npm run check`, `npm run build` and `npm audit --audit-level=high` pass. The dependency audit reports zero vulnerabilities at repair time. Twelve regression tests include actual GLTF parsing, reduced geometry and independently seekable door animations.

The first GitHub production run passed install/check/build/audit and 11 browser checks. Two browser checks exposed an ambiguous quality-selector accessible name; the control now has an explicit label. The branch's latest required workflow is the authoritative final browser result; retain its HTML report and failure artifacts with the review.

## Before a client launch

Use docs/DEPLOYMENT.md and docs/VALIDATION.md. Test representative iPhone Safari, Android Chrome and desktop GPUs with the actual client models/media, throttled network, forward/reverse/restore, long-running route and quality changes, and touch/screen-reader navigation. Capture frame-time percentiles, memory trend and visual review at each scene boundary. Set project-specific acceptance budgets before measuring. Do not substitute software-rendered CI for these measurements or advertise a numeric readiness score unsupported by evidence.
