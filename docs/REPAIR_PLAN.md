# Production hardening plan

Preserve the persistent Canvas, Lenis scroll owner, pure scene sampler and configuration-driven narrative. Implement the audit findings on a review branch. No automatic main merge or deployment is part of this repair.

## Reference scene plan

The shipped reference uses an original, redistributable animated GLB architectural pavilion. The generator and license are included. It is a real asset-loading/animation/composition fixture, not a claim of photorealistic client art.

| Scene     | Purpose                   | Camera start → end / path            | Persistent object                 | Environment / copy / interaction                       | Handoff / assets                                               |
| --------- | ------------------------- | ------------------------------------ | --------------------------------- | ------------------------------------------------------ | -------------------------------------------------------------- |
| Arrival   | Establish the pavilion    | Front wide → approach / dolly        | Pavilion stays at world origin    | Dusk; readable introduction; semantic scene navigation | Shared geometry; pavilion GLB                                  |
| Approach  | Reveal depth and entrance | Approach → doorway / arc             | Same pavilion                     | Warm key light; explain space                          | Endpoint-matched move; pavilion GLB                            |
| Threshold | Open the entrance         | Doorway → interior / threshold       | Same pavilion, door clip scrubbed | Interior light; entrance detail button                 | Door animation follows scene-local progress in both directions |
| Interior  | Explore the room          | Interior → lateral room view / crane | Persistent environment            | Interior narration and keyboard-accessible details     | No Canvas remount; camera clearance authored in fixture        |
| Reveal    | Re-establish exterior     | Room → exterior overlook / pullback  | Same pavilion                     | World/light color handoff                              | Reverse-safe sampler and scene layers                          |
| Finale    | Reach conversion          | Exterior → final wide / dolly        | Persistent final object           | Final CTA remains visible at progress 1                | Stable ending; same GLB                                        |

Each industry recipe will have different camera endpoints, ranges, hero transforms, atmosphere and original fixture assets; changes are validated and continuity-tested. Mobile framing is authored/fit separately. Reduced motion uses a stationary world and ordinary semantic document flow.

## Order and acceptance

1. Deterministic install and mandatory gates; shared schema and negative tests.
2. Correct sampled endpoints, initial/final copy, keyboard/focus, reduced motion and scroll restoration.
3. Quality ownership, conservative initialization, bounded resource loading, media and WebGL recovery.
4. Original asset fixtures and five distinct recipes; authoring/diagnostic tools.
5. Production build, dependency audit, automated browser viewport/failure/route tests and evidence report.

Physical-device thermal/GPU capacity cannot be certified by software emulation. Record those remaining release checks explicitly; do not assign a fabricated 100/100 score.
