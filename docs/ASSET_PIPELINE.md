# Production asset pipeline

Register all runtime URLs in config/asset-manifest.json. Local entries use {path,bytes,sha256}; byte counts and supplied hashes must match. Audits recurse and fail missing references, unregistered runtime assets, per-file excess and total excess. Remote HTTPS assets require declared bytes; response availability, CORS and remote size still require deployment checks.

The original reference GLBs are generated by scripts/generate-assets.mjs and licensed under the repository MIT license. Each has a low variant; tests verify lower triangle counts. The pavilion embeds door-slide. These are integration fixtures, not substitute client artwork.

GLTFModel, AnimatedGLTF and ScrubbedGLTF clone hierarchy/skeleton per instance. Final owner release disposes cached resources with a short grace period. Never dispose shared source geometry/materials from an individual instance. Custom texture/material overrides must be cloned and owned explicitly.

Draco and Meshopt wiring comes from Drei. KTX2 is connected to the loader and renderer support detection. Dev/build copies Draco/Basis decoders from the locked Three version to public/decoders. Keep these files in deployment output. Test the exact codec encoder/version and external textures used by your project.

Use heroLowModel or model lowUrl for LOD assets. Nonpersistent scene models mount near their required scenes within runtime.preloadMb; persistent assets remain resident by choice. This is bounded neighborhood loading, not automatic streaming of arbitrary 200 MB source models. Split rooms/zones and textures before delivery.

A compressed file byte budget does not bound decoded GPU memory. Choose texture dimensions/formats, triangle/draw-call budgets and initial critical bytes using measured hardware. 4K/8K source textures are not automatically appropriate for mobile. Large source Blender/raw video/EXR belongs outside the deployed repository; deliver versioned optimized outputs through a CDN.

Video owns its HTML media element/texture, records readiness and errors, coalesces seeks while seeking is true, and clears src on cleanup. Encode scrub video with frequent keyframes; verify reverse/fast seeking and mobile Safari. Missing media never owns or hides primary page copy.
