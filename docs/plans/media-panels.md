# Cinematic media sequence

Optional media augments each existing scene; no second canvas or scroll controller.

| Scene phase | Purpose | Camera/object/environment | Media and typography | Interaction | Transition |
| --- | --- | --- | --- | --- | --- |
| Incoming | Establish next subject | Existing configured starting state and path | Incoming panel translates over previous; counter-moving inner image; headline settles after boundary | Existing native links and details | Start during final configured fraction of prior scene |
| Hold | Inspect composition | Existing sampled camera, hero and lighting | Full-frame image/video, small uniform zoom; independent copy timing | Native actions remain available | Hold until next handoff |
| Outgoing | Hand off subject | Preserve configured ending state and next start | Previous image retreats 35% while next covers it; no nonuniform product stretch | No gesture interception | Fully reversible, exact seeks from master progress |

Required assets: optional authored scene media and mandatory video poster, registered in asset manifest. Lab preview uses original lightweight SVG illustrations, clearly labeled as fixtures. Per-scene desktop/mobile focal crops, direction, overlap, zoom and text timing are validated. Baseline images remain visible in semantic sections with no JS or reduced motion. Animation uses a decorative fixed layer and existing readable narrative. Only current and neighboring media are mounted in the moving layer; video is paused outside its visible interval and on page hiding. No external demo code copied.
