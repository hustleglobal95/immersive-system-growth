# Production offer boundary

Forge 4.0 is designed to support premium, custom marketing experiences with a repeatable production workflow. The repository supplies the engine and control plane; a project fee must still cover original art direction, licensed assets, copy, integration work, device QA, launch and client-specific risk.

## What can be delivered efficiently

- cinematic product, restaurant, property, automotive and SaaS launch experiences
- continuous scroll-directed 3D storytelling with reversible scene choreography
- named-part product explosions and reassembly from suitable GLB assets
- responsive camera direction, lighting, material treatment, media panels, masks and layered transitions
- accessible semantic content, menus, conversion actions and reduced-motion behavior
- static JSON, allowlisted CMS feeds and Shopify Storefront content
- isolated client configurations, review PRs, protected builds and consent-aware performance telemetry

## Definition of a premium-ready project

A premium delivery is not a template swap. It includes a signed scene plan, source-asset rights, approved desktop/mobile art direction, measurable performance targets, content/integration acceptance criteria, accessibility review, forward/reverse timeline QA, representative physical-device evidence, preview approval and a protected production release.

## Scope controls

Price and schedule should change when a project adds photoreal asset creation, complex character animation, configurators, accounts, bespoke checkout, multilingual editorial workflows, unusual CMS migrations or a large device/browser matrix. Forge reduces repeated engineering effort; it does not remove creative production, integration uncertainty or launch responsibility.

Use this boundary in proposals so the platform strengthens margin and delivery confidence without promising that every concept, asset or device can ship at the same fixed effort.
