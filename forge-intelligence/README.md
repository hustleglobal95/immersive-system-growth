# Forge Intelligence

Persistent studio-level memory for Forge Director Intelligence.

- `precedents/` — structured design reasoning and transferable lessons, not mood boards.
- `projects/` — portfolio fingerprints and evidence-backed project lessons.
- `taste/` — layered pairwise preference calibration. `profile.json` is studio taste; `operators/` and `projects/` hold optional secondary layers. Taste never becomes a style-cloning mandate.
- `calibration/` — human benchmark cases for Council/judge reliability.
- `category-patterns/` — category defaults, clichés and anti-patterns used by originality review.

Approved project memory can additionally store Creative DNA, Art Direction, selected visual language and discipline grammars. Proposed mutations are not remembered unless explicitly selected for the approved creative record.

Director Intelligence automatically considers memory from prior projects while excluding the current project's own nodes from anti-repeat scoring. Studio intelligence must preserve provenance and confidence and must not turn weak correlations into creative laws.
