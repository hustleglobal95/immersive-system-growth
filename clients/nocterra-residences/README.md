# NOCTERRA Residences

Fictional luxury waterfront demonstration project for Forge.

NOCTERRA Residence 01 combines the existing reference automotive and pavilion assets into one continuous cinematic journey. It is intentionally isolated from the core engine so the demonstration can evolve without hardcoding client-specific behavior into Forge.

## Journey

1. Arrival: establish the complete world.
2. The Machine: make the grand tourer the first subject.
3. Detail: compress into automotive surface and light.
4. Profile: return to a controlled automotive hero frame.
5. Handoff: leave the vehicle and redirect attention to the residence.
6. Exterior: reveal facade, terrace and glass.
7. Threshold: enter through the animated architectural doorway.
8. Interior: slow the pace and create visual rest.
9. Material: move into a close material study.
10. Terrace: use architecture as a natural transition back outside.
11. Horizon: deliver the largest waterfront composition.
12. Private Presentation: settle the camera and expose the conversion CTA.

## Assets

The first runnable version deliberately uses Forge's bundled reference models:

- `/models/reference/automotive.glb`
- `/models/reference/pavilion.glb`

Replace those with production art without changing the narrative contract.

## Use

Activate locally with:

`npm run project:activate -- nocterra-residences`

Then run the normal Forge validation and development workflow.

This brand and project are fictional.
