# Immersive System Growth

The Immersive Site Forge is a production-minded starter system for cinematic, immersive 3D websites using Next.js, React Three Fiber, Three.js, GSAP, Lenis, Zustand, and optional postprocessing.

This repository contains the full architecture for persistent WebGL experiences, normalized cinematic timelines, camera choreography, scene transitions, interactive hotspots, animated assets, adaptive quality, reduced-motion support, Scene Lab tooling, recipes, validation scripts, and Claude Code workflows.

## Quick start

```bash
npm install
npm run check
npm run build
npm run dev
```

Open `/` for the cinematic demo and `/lab` for the Scene Lab.
