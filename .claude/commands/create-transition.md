# /create-transition

Design the scene handoff using threshold pass, occlusion, persistent-object handoff, surface dive, model exchange or lighting handoff. Do not default to a full-screen fade. Explain how the transition works in reverse before implementing it.

Completion gate: follow `docs/VALIDATION.md`; run `npm run check`, `npm run build`, `npm audit --audit-level=high` and the production browser suite. Record camera/scroll ownership, asset changes and any unverified physical-device checks in the review.
